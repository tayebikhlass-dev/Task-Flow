
# TaskFlow

TaskFlow est une application de gestion et de suivi des tâches au sein des projets. Elle permet aux utilisateurs d’organiser leur travail et de suivre facilement l’avancement des tâches.

---

##  Fonctionnalités
- Création de nouvelles tâches
- Modification des tâches
- Changement de statut des tâches (À faire / En cours / Terminé)
- Organisation des tâches par projets
- Notifications (si incluses dans le projet)

---

## ⚙️ Technologies utilisées
- Java
- UML
- Design Patterns (Observer, Factory Method)
- Programmation Orientée Objet (POO)

---

##  Exécution du projet
1. Ouvrir le projet dans IntelliJ IDEA
2. Vérifier la configuration du JDK
3. Lancer la classe principale `Main.java`

---

## Structure du projet
- models/ → Classes principales (Tache, Projet, Utilisateur)
- patterns/ → Implémentation des Design Patterns
- test/ → Tests et exécution
